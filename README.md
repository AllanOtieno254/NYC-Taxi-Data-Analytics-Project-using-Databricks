# 🚕 NYC Taxi Data Analytics Project using Databricks 📊

Excited to share one of the projects I recently worked on while learning and exploring **Databricks** for **Data Analytics & Data Engineering**.

In this project, I analyzed the **NYC Taxi Trips Dataset** containing **21,000+ ride records** from **January–February 2016** to uncover insights about transportation patterns, trip behavior, fares, and geographic activity across New York City.

---

# 🔍 Key Analysis Performed

* Time Series Analysis of daily trip trends
* Hourly & Weekly ride activity analysis
* Distance vs Fare correlation analysis
* Geographic pickup hotspot analysis using ZIP codes
* Peak demand identification
* Trip distribution analysis by distance ranges
* Interactive dashboard creation & filtering

# 📈 Some Interesting Insights

* ✅ **6 PM** was the busiest ride hour
* ✅ Most trips were **short-distance rides (1–3 miles)**
* ✅ Manhattan ZIP codes had the highest pickup volumes
* ✅ Fare amount showed a strong positive correlation with trip distance
* ✅ Weekend and weekday ride patterns were significantly different

# 📚 Dataset Columns Included

| Column Name             | Description                |
| ----------------------- | -------------------------- |
| `tpep_pickup_datetime`  | Pickup timestamp           |
| `tpep_dropoff_datetime` | Dropoff timestamp          |
| `trip_distance`         | Distance traveled in miles |
| `fare_amount`           | Fare charged for the trip  |
| `pickup_zip`            | Pickup ZIP code            |
| `dropoff_zip`           | Dropoff ZIP code           |
